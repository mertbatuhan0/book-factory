# 📚 Book Factory

**Book Factory** is a lightweight Python application that generates random `Book` objects from a predefined list. It uses **uv** for fast package and environment management.

---

## 🚀 Features

* **Book Class:** Encapsulates book details such as `title` and `author`.
* **Random Generation:** Uses `GenerateBooks()` to randomly select and instantiate a book object.
* **Modern Tooling:** Managed with `uv` for ultra-fast dependency resolution.
